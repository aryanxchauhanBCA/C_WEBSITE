1. Write a program of recursion and display the output.

Code 
#include <stdio.h>

int x = 1;

void fun()
{
    if(x == 5)
    {
        printf("%d", x);
        x++;
        fun();
    }

    printf("A");
}

int main()
{
    fun();

}
Output 
5AAAAA
